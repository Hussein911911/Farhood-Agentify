# واحة — مثال واجهة عراقية تجريبية

ملفات الواجهة النهائية منتقلة إلى `public/waha/` حتى تُنشر مع تطبيق المنصة على نفس النطاق (زر «إدارة المطعم» يفتح `/`).

- `public/waha/index.html` — واجهة واحة العراقية (منيو مربوط بالقائمة العامة، بدون طلب أو حجز).
- `public/waha/farhood-api.mjs` — عميل API العام الآمن (RPC فقط، بدون مفاتيح سرية).
- المستودع المستقل لموقع واحة يُجهَّز في `../waha-restaurant` عند ربطه بـ Cloudflare Pages.

نسخة الموقع وثائقها الكاملة موجودة في `../waha-restaurant/README.md` عند إنشاء المستودع. اختبارات الموحد موجودة في `tests/external-api.test.mjs` (`npm test`).
