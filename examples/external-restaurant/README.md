# تجربة ربط موقع خارجي

هذا مثال مستقل بواجهة HTML/CSS/JavaScript يقرأ البيانات العامة من Supabase عبر `get_restaurant_site`. لا يحتاج كود المنصة للعرض، ويمكن تبديل الواجهة مع الاحتفاظ بطريقة الربط. لا يرسل طلبات أو بيانات خاصة، ولا يتجاوز صلاحيات المدير أو ميزة الاشتراكات.

## التجربة

1. أنشئ مطعماً تجريبياً بمعرّف slug، وباقة واشتراك سارٍ من لوحة الأدمن، واضبط الموقع كـ«منشور» وأضف صنفاً متوفراً. تعمل الخدمة خلال فترة السماح الحالية كافتراض مؤقت.
2. شغّل من جذر المشروع: `python3 -m http.server 8000 --directory examples/external-restaurant`، ثم افتح `http://localhost:8000` على جهازك. في بيئات المعاينة يجب فتح الرابط الذي توفره البيئة للمستخدم بدلاً من localhost.
3. أدخل رابط مشروع Supabase، المفتاح **العام Publishable** (يبدأ بـ `sb_publishable_`) وslug المطعم، ثم اضغط عرض. لا تُدخل أبداً `service_role` أو `sb_secret_`.
4. اختبر بعد ذلك مطعماً آخر، ومعرّفاً غير موجود، ومطعم غير منشور أو منتهي الاشتراك. هذه الحالات غير المتاحة تعرض رسالة عامة بدون بيانات المطعم. يجب اختبار العزل مع حسابين مختلفين قبل الإنتاج.

## عقد الربط الحالي

`POST https://<project>.supabase.co/rest/v1/rpc/get_restaurant_site` مع `Content-Type: application/json` و`apikey: <publishable key>` وجسم `{"p_slug":"restaurant-slug"}`. هذا مفتاح عام وليس كلمة مرور؛ لا تستخدمه كرمز Bearer. نطلب فقط بيانات عامة، مع حراسة الوصول في قاعدة البيانات؛ لا تعتمد على slug أو مفتاح عام كأسرار.

النتيجة `status: unavailable` عندما لا يكون الموقع متاحاً، أو `status: available` مع `name, headline, description, phone, address, hero_image_url, logo_url, opening_hours, accent_color, items`. كل عنصر في `items` يحتوي `name, description, category, price_iqd`. الأصناف غير المتاحة لا تُرجع. تنسيق الخطأ والحقول الحالية أولي وغير مضمون الاستقرار كواجهة عامة نهائية؛ لا تستخدمه للبيانات الخاصة أو المدفوعات أو إدارة المطعم.

هذا الربط يمنع تسليم بيانات المنيو عند توقف الاشتراك، لكنه لا يضمن إخفاء ملفات موقع خارجي مستقل أو محتوى مخزّن عند طرف آخر. اختبر من متصفح حقيقي واستضافة فعلية وحالة CORS قبل التسليم. لا توجد بعد API مستقرة للطلبات أو مصادقة المدير في المواقع الخارجية، ولا حدود استخدام أو مراقبة خاصة بهذه الواجهة. الاختبارات المرفقة تستخدم شبكة وهمية ولا تُثبت صحة الربط الحي أو عزل المستأجرين.
