# Farhood Agentify

المرحلة الأولية لإدارة المطاعم والاشتراكات. الواجهة تدعم تسجيل دخول Supabase للمشرف وعرض المطاعم وإضافتها، وإضافة الباقات وتعديل أسمائها وأسعارها وحالة إتاحتها وتسجيل الاشتراكات أو إلغائها في قاعدة البيانات. لا تنشئ الإضافة موقعاً أو حساب عميل أو اشتراكاً تلقائياً. بقية الأقسام قيد التطوير.

## التشغيل

```bash
npm install
cp .env.example .env.local
# ضع رابط المشروع والمفتاح العام publishable في .env.local
npm run dev
```

استخدم المفتاح العام فقط في متغيرات `NEXT_PUBLIC_`؛ لا تضع مفتاح service role أو أي مفتاح سري في الواجهة أو المستودع. عند النشر اضبط المتغيرات نفسها في Cloudflare وأعد البناء. يجب اختبار توافق إصدار Next.js وطريقة النشر المختارة.

## Supabase والصلاحيات

تم تطبيق مخطط `supabase/migrations/20261108000100_foundation.sql` على مشروع Farhood-Agentify المرتبط. يتضمن المطاعم والعضويات والباقات والمميزات والاستثناءات والاشتراكات وطلبات الدفع، مع تفعيل RLS. حساب المشرف لا يُمنح تلقائياً: يجب إنشاء حساب Supabase Auth ثم تعيينه من جهة موثوقة في جدول `platform_admins`. لا توجد صفحة تسجيل عام في التطبيق. يجب اختبار RLS بحسابات مختلفة قبل الإنتاج.

قائمة المطاعم وملخص الاشتراكات يُقرآن من Supabase؛ الحالة المعروضة تستنتج من تاريخ الانتهاء وفترة السماح المسجلة، وليست آلية لوقف الموقع. إدارة الاشتراكات أولية: لا توجد بعد آلية تجديد متكاملة أو حفظ للسعر وقت الاشتراك، أو تذكير وإيقاف المواقع، أو الثيمات. توجد واجهة أولية للمشرف لتسجيل الدفعات يدوياً ومراجعتها والمصاريف؛ التقارير تعرض مجموع الدفعات المؤكدة مطروحاً منها المصاريف لكل عملة على حدة لجميع الفترات، ولا تتحقق من التحويلات أو تفعّل الاشتراك. هذه ليست محاسبة مكتملة. مدة الاشتراك تحسب بإضافة شهر أو سنة مع تقريب نهاية الشهر، حسب الوقت المحلي للمشرف عند الإدخال. الاشتراك السابق المسجل بحالة فعّالة يجب إلغاؤه يدوياً قبل تسجيل بديل. لم تُدرج أسعار افتراضية لأنها لم تُعتمد. لم يُختبر تسجيل الدخول والإضافة والمراجعة من طرف لطرف عبر المتصفح بعد.

تم تطبيق `supabase/migrations/20261108000200_platform_expenses.sql` لإضافة مصاريف المنصة مع سياسة تتيحها للمشرف فقط. بيانات الدفع والمصاريف يجب مراجعتها بعناية، ولا توجد حالياً آلية كشف تكرار التحويلات أو ربط دفعة باشتراك أو استرجاعها.

يمكن للمشرف تسجيل المميزات وتعيينها للباقات أو إضافة استثناءات لكل مطعم من قسم الباقات. هذه إعدادات بيانات فقط: لا تُطبّق المميزات على مواقع المطاعم أو تمنع الوصول إليها بعد، ويلزم تنفيذ تحقق آمن من الاشتراك والاستثناءات عند بناء كل ميزة.

## Cloudflare Workers (الواجهة الحالية)

المشروع الحالي يُصدّر كملفات ثابتة (`out`) وتُنشر عبر Workers Static Assets باستخدام `wrangler.jsonc`. إعدادات Git builds: أمر البناء `npm run build`، أمر النشر `npx wrangler deploy`، وأمر معاينة الفروع `npx wrangler versions upload`. اضبط متغيري `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` كمتغيرات بناء؛ يُضمّنان في الواجهة عند البناء ويجب إعادة البناء بعد تغييرهما. لا تستخدم مفتاح service role. إعداد static export مناسب للوضع الحالي فقط؛ أي وظيفة Next.js تحتاج خادماً تتطلب تعديل طريقة النشر. النشر يتطلب رفع الفرع وتحديده في إعدادات البناء على Cloudflare.

إيقاف إتاحة باقة يمنع اختيارها للاشتراكات الجديدة فقط، ولا يلغي الاشتراكات السابقة. لا يُحفظ سعر تاريخي للاشتراك بعد، لذا لا يُعتمد على السعر الحالي لمعرفة ما دُفع سابقاً.

## التجديد اليدوي

تم تطبيق `20261109000100_subscription_renewals.sql` على مشروع Supabase. مدير المنصة يربط دفعة مؤكدة باشتراك مسجل فعال، ويختار شهراً أو سنة؛ التجديد قبل الانتهاء يضيف للانتهاء، وبعد الانتهاء يبدأ من وقت التجديد. الدالة تتحقق من صلاحية المشرف وملكية المطعم وحالة الدفعة وتمنع إعادة استخدام الدفعة في التجديدات. تحديث الانتهاء وإنشاء سجل التجديد ينفذان بمعاملة واحدة. القيم المسجلة للدفعة نسخة وقت التجديد، ولا توجد مطابقة تلقائية للمبلغ أو العملة؛ مسؤولية المشرف التأكد منهما. تنبيه: الاشتراكات والدفعات السابقة المنشأة يدوياً لم تكن مرتبطة، فلا يمكن للنظام معرفة إن كانت دفعة قد استُخدمت يدوياً قبل توفير ميزة التجديد. التجديد لا يفعّل ميزة إيقاف المواقع أو التنبيهات، وما زال يحتاج اختباراً كاملاً بالحسابات قبل الإنتاج.

## لوحة مدير المطعم

تم تطبيق `20261109000200_restaurant_manager_access.sql`. يستطيع مشرف المنصة ربط بريد حساب موجود ومؤكد في Supabase Auth بمطعم كمالك أو مدير. لا ينشئ هذا الربط الحساب ولا يرسل دعوة. يرى المدير المطاعم المربوطة به وحالة الاشتراك وتنبيهاً قبل الانتهاء بيومين وفترة السماح. يمكن لمدير المطعم إرسال تفاصيل تحويل للمراجعة بعد الاتفاق مع المشرف، ومتابعة آخر 20 طلباً؛ هذا لا يؤكد وصول التحويل ولا يجدد الاشتراك تلقائياً. سياسات الاشتراكات والمدفوعات تحد قراءة الأعضاء بالمالك والمدير مع إبقاء وصول المشرف. لم تُختبر السياسات من طرف لطرف بعد؛ يجب اختبار حسابين لمطعمين مختلفين قبل الإنتاج. ليس هناك إيقاف موقع فعلي أو تحرير منيو أو إشعار خارجي حالياً.

تم تطبيق `20261109000300_manager_renewal_request.sql`: التقديم متاح للمالك أو المدير المربوط بالمطعم فقط، والدالة تنشئ طلباً بحالة انتظار بعد فحص المدخلات وتمنع طلباً جديداً إذا كان للمطعم طلب بانتظار المراجعة. لا يتم التحقق من التحويل أو تجديد الاشتراك آلياً. يجب اختبار العزل والتدفق من الطرفين قبل الإنتاج.

## أول ثيم مطعم

تم تطبيق `20261109000400_restaurant_site_menu.sql`. يدير المشرف عنوان الواجهة والوصف والعنوان ورقم التواصل ولون الثيم ورابط صورة HTTPS وحالة النشر من «الثيمات والمواقع». مدير المطعم يستطيع إضافة أصناف المنيو وتعديلها أو إخفاءها أثناء الاشتراك الساري أو فترة السماح. الموقع العام متاح برابط `/?site=slug` عند نشره ووجود اشتراك ضمن مدته أو فترة السماح؛ خلاف ذلك يُرجع استجابة عامة غير متاح. هذا افتراض مؤقت لتشغيل الموقع خلال فترة السماح بانتظار تأكيد صاحب المشروع. تعرض الدالة العامة حقول الموقع والأصناف المتوفرة فقط. لا يوجد بعد سابدومين فعلي، رفع صور أو شعار، طلبات، ربط مزايا الباقة، أو اختبار أمني شامل لعزل المطاعم. الروابط الخارجية للصور بحاجة لاستضافة HTTPS، وقد لا تعمل إذا منعت الخدمة تضمينها. يلزم اختبار المستخدمين المختلفين وحالات الانتهاء قبل الإنتاج.

إعدادات الثيم تشمل رابط لوغو HTTPS وأوقات عمل كنص، وتتيح للمشرف أيضاً إدارة المنيو من صفحة إعداد الموقع. تُطبق إضافة الأعمدة ودالة العرض بمهاجرة `20261109000500_site_branding_hours.sql`. الروابط الخارجية لا ترفع ملفات ولا تضمن استمرار الصورة، ولا تزال الميزة بحاجة لاختبار شامل في المتصفح والصلاحيات.

من «الثيمات والمواقع» يستطيع المشرف معاينة الثيم قبل النشر: المعاينة تعرض تعديلات الهوية الحالية حتى لو لم تُحفظ، مع أصناف المنيو المتوفرة المحفوظة. تُحمّل الأصناف بصلاحيات حساب المشرف، والمعاينة داخل اللوحة فقط؛ الرابط العام يبقى خاضعاً للنشر والاشتراك. لتحديث المعاينة بعد تعديل المنيو أو الهوية اضغط زر المعاينة مرة ثانية. لم يُختبر التدفق الكامل عبر المتصفح بعد.

## طلبات الباقات الأولية
